FUNCTIONALITY INCLUDED
1. Navigation: Allows customers to move between the Home, Products, Order Now, Special Offers, Contact, About and Reviews pages.
2. Product Display: Displays available perfumes and gift sets, including product images, descriptions and prices.
3. Image Lightbox: Allows customers to click on product images to view enlarged pictures. The lightbox can be closed using the close button, clicking outside the image or pressing Escape.
4. Shopping Cart: Allows customers to add perfumes to their cart, increase or decrease quantities, remove products and clear the cart.
5. Cart Total Calculation: Automatically calculates the total cost of selected products based on their prices and quantities.
6. Cart Storage: Uses browser localStorage to save cart items, allowing customers to return to their saved cart using the same browser and device.
7. Order Processing: Allows customers to review their selected products and proceed to the order page to provide their order information.
8. Delivery Options: Allows customers to choose between standard delivery, express delivery or free collection.
9. WhatsApp Ordering: Allows customers to send their order details to the business through WhatsApp for communication and confirmation.
10. Special Offers: Displays available promotions and discounts to inform customers about current offers.
11. Contact Information: Provides customers with the business's contact details so they can make enquiries.
12. Customer Reviews: Provides a section for displaying customer feedback and reviews.
13. Responsive Design: Allows the website to adjust its layout to different screen sizes, including desktop computers, tablets and mobile phones.

Overall functionality: The website makes it easier for customers to browse perfumes, select products, calculate their order totals and submit order enquiries through WhatsApp.
